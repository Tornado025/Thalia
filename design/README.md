# Design reference

`*.dc.html` = one file per screen, exported from the Thalia design canvas
(https://claude.ai/artifact/399NGUjg5XGTgEM4TZoLqs). They use a canvas runtime, so they
won't render standalone — read them as reference for layout, exact colors, spacing and copy.
Implement in React Native using the tokens in docs/SCREENS.md, not by porting the HTML.
